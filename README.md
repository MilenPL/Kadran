# Kadran - Custom multi widget engine featuring custom clock functions
Designed originally for One UI, so it might not work in rare cases.

Important!: versions 1.8 and newer are separate app. When updating from v1.7.1 to v1.8 you need to export your clock layouts, then you can uninstall the old app and install the new one (v1.8). Then you can import the layouts. You might need to give the app it's permissions again after the download of the version v1.8. later versions should be updating normally on base of v1.8.

Versions v1.8 and newer are considered safe by safety scan. 

I'm sorry for skipping so many versions, especially all between 1.1 and 1.5, but there wasn't that much content difference and there were lots of bugs and design flaws.

I added some screenshots of how it looks like in main/Screenshots

If you find any bugs or other problems, please report them. I will try to fix them asap.
